# GEN AI Practice - Variation 3 (security theme)

Practice scripts for Word Embeddings (4-6) and the RAG series (16-32).

Install: `pip install gensim scikit-learn pandas sentence-transformers chromadb langchain-text-splitters tiktoken rank-bm25 python-dotenv groq google-genai`

Practice_28-32 need `GROQ_API_KEY` or `GEMINI_API_KEY` in a `.env` file. Run 29-32 from inside their folder (they import Practice_28).
